1. Who we are

ChatVeil ("ChatVeil", "we", "us") is a free browser extension, "ChatVeil – Privacy Blur for WhatsApp™ Web", available on the Chrome Web Store. It visually blurs WhatsApp Web content so people near your screen cannot read it. This policy explains how the extension and this website handle information.

ChatVeil is an independent tool. It is not affiliated with, endorsed by or sponsored by WhatsApp LLC or Meta Platforms, Inc.

2. Information we collect

None. ChatVeil does not collect, transmit or receive any personal information or usage data. Specifically, it does not collect:

  • Personally identifiable information (name, email, phone number, address)
  • Message content, contact names, photos, media or any other WhatsApp data
  • Browsing history, web activity or the websites you visit
  • Location, IP address or device identifiers
  • Authentication information, passwords or financial information
  • Analytics, crash reports, telemetry or usage statistics

The extension contains no analytics, advertising or tracking code and loads no remote code.

3. What is stored on your device

To remember your preferences, ChatVeil saves a small settings object using Chrome's chrome.storage.local API. This data stays in your browser on your computer and is never sent anywhere.

Stored itemPurpose
Privacy settingsWhich items to blur, active mode, blur style and strength, reveal method and delay, hold-to-peek key.
Automation settingsAuto privacy options, smart schedule days and times, tab disguise title, quick-button preference.
PIN lock dataA random salt and a SHA-256 hash of your PIN (never the PIN itself), plus lock preferences.

Removing the extension from Chrome deletes all of this data.

4. WhatsApp Web content

ChatVeil runs only on https://web.whatsapp.com/. It adds CSS classes to page elements so the browser displays them blurred. To tell group chats apart from one-to-one chats, it briefly checks the short text under the chat title in the page header (for example "online" or a participant list). That check happens in memory, the result is discarded immediately, and it is never stored, logged or transmitted. ChatVeil does not read, save or send your messages.

5. Browser permissions

PermissionWhy ChatVeil needs it
storageTo save your settings locally, as described in section 3.
Host access: web.whatsapp.comTo apply the visual blur, lock screen and quick button on WhatsApp Web. ChatVeil has no access to any other website.

ChatVeil does not request access to your tabs, history, cookies, downloads, clipboard, identity or any other website.

6. Sharing and selling data

Because ChatVeil collects no data, there is nothing to share. We do not sell, rent, transfer or disclose user data to any third party, and we do not use data for advertising, creditworthiness, lending or any purpose unrelated to the extension's single purpose.

7. PIN lock

If you set a PIN, ChatVeil creates a random salt and saves only a SHA-256 hash of the salt and PIN. Your actual PIN is never stored or transmitted. The PIN lock is designed as a privacy screen against people near your computer. It is not a security boundary, and it does not replace locking your computer or your WhatsApp account's own security features.

8. This website

This website is a static site hosted on GitHub Pages. It uses no cookies, analytics, advertising, fonts or scripts from third parties. Like any web host, GitHub may process technical information such as your IP address to deliver the site and keep it secure. See the GitHub Privacy Statement. If you email us, we use your message and email address only to reply.

9. Chrome Web Store Limited Use

ChatVeil's use of information complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Any information handled by the extension is used only to provide its single purpose: visually hiding WhatsApp Web content on the user's own screen.

10. Your choices and rights

  • Change or reset any setting at any time from the ChatVeil popup.
  • Remove your PIN in the popup's Lock tab (your current PIN is required).
  • Delete all stored data by removing ChatVeil at chrome://extensions.

Because we hold no personal data about you, there is nothing for us to access, correct, export or delete on our side. You can still contact us with any privacy question, including requests under the GDPR, the UK GDPR, the CCPA/CPRA or the UAE PDPL.

11. Children

ChatVeil is not directed at children under 13 (or the minimum age in your country), and it collects no data from anyone, including children.

12. Changes to this policy

If this policy changes, we will update the "Last updated" date above and describe the change in the extension's release notes. If ChatVeil ever started collecting data, we would ask for your consent first.
