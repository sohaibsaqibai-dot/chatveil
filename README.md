## What is ChatVeil?

ChatVeil is a free browser extension for Google Chrome, Microsoft Edge and Brave that blurs WhatsApp Web (web.whatsapp.com) so people near your screen, or anyone watching a screen share, can't read your chats. Hover over any message to reveal it. The extension runs entirely in your browser: it makes no network requests, collects no data and needs only one permission (`storage`).

## Features

| Feature | What it does |

## Privacy

- **No data collected.** No analytics, ads, cookies or remote code.
- **No network requests.** The extension never contacts a server.
- **Local settings only**, stored with `chrome.storage.local`; the PIN is saved as a salted SHA-256 hash.
- **Permissions:** `storage` + access to `web.whatsapp.com` only.

## FAQ

**How do I blur WhatsApp Web?** Install ChatVeil, open web.whatsapp.com and your chats are blurred automatically. Hover to read.

**How do I hide WhatsApp Web while screen sharing?** Choose *Screen share* mode before your call. Everything is covered and hover is turned off.

**Can I lock WhatsApp Web with a PIN?** Yes. Set a 4–8 digit PIN in the Lock tab.

**Is it free?** Yes, completely free.

**Is ChatVeil made by WhatsApp or Meta?** No, it's an independent tool.
